## 수집하는 정보

클라우드 버전을 사용하면 입력한 재무 데이터(거래, 예산, 계좌 이름)와 인증에 필요한 이메일 주소를 저장합니다. 직접 호스팅하는 경우 당사로 전송되는 데이터는 없습니다.

## 데이터 이용 방법

재무 데이터는 서비스 제공 목적으로만 사용합니다. 데이터를 판매하거나 광고에 사용하지 않습니다. MCP 연결을 승인하는 등 사용자가 제3자 클라이언트에 데이터를 제공하도록 지시한 경우에만 해당 클라이언트에 데이터를 제공합니다. 각 워크스페이스는 Postgres의 행 수준 보안으로 격리됩니다.

## MCP 및 제3자 AI 클라이언트

AI 클라이언트를 호스팅형 MCP 서비스에 연결하면 Expense Budget Tracker는 OAuth 인가 요청, 호출된 도구와 해당 인수, 선택한 워크스페이스, 조회 요청을 수행하거나 승인된 쓰기 작업을 반영하는 데 필요한 재무 기록을 처리합니다. MCP를 통해 변경한 내용은 웹 앱에서 변경한 내용과 마찬가지로 호스팅 서비스의 재무 데이터에 반영됩니다.

서비스는 등록된 클라이언트의 이름과 리디렉션 URL, 연결 및 권한 범위의 메타데이터, 생성·활동·철회 시각을 저장합니다. OAuth 인가 코드와 액세스 토큰 및 갱신 토큰은 단방향 해시로 저장합니다. OAuth 토큰 원문은 저장하지 않습니다. MCP 서비스는 각 도구 요청을 받아 요청한 결과를 반환하지만, AI 클라이언트의 대화를 제품 내 대화 기록으로 저장하지 않습니다.

AI 클라이언트는 별도의 제3자입니다. 자체 약관 및 개인정보 처리방침에 따라 프롬프트, 도구 인수, 반환된 재무 데이터를 처리하거나 보관할 수 있습니다. 연결하기 전에 해당 클라이언트의 개인정보 처리방침을 확인하세요. **설정 > 에이전트 및 프로그램 접근 권한**에서 언제든지 MCP 연결을 해제할 수 있습니다. 아래 안내에 따라 설정에서 사용자 계정과 관련 호스팅 데이터를 삭제할 수 있습니다.

## 데이터 저장

클라우드 데이터는 AWS RDS(Postgres)의 eu-central-1 리전에 저장되며 매일 자동으로 백업됩니다. 데이터는 저장 및 전송 시 암호화됩니다.

## 쿠키

인증에 `session` 쿠키(HttpOnly, Secure, SameSite=Lax)를 사용합니다. 추적 쿠키나 제3자 분석 도구는 사용하지 않습니다.

## 데이터 삭제

앱의 설정에서 언제든지 사용자 계정과 관련 데이터를 모두 삭제할 수 있습니다. 자체 호스팅의 경우 데이터베이스를 직접 관리합니다.

## 오픈 소스

전체 소스 코드가 공개되어 있어 앱이 데이터를 어떻게 처리하는지 직접 검토할 수 있습니다.
