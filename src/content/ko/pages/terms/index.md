## 서비스

Expense Budget Tracker는 오픈 소스 개인 재무 관리 도구입니다. 베타 기간에는 호스팅형 웹사이트, 앱, API 및 MCP 서비스를 현 상태 그대로 무료로 제공합니다.

## 서비스 제공자

호스팅형 Expense Budget Tracker 서비스는 SAMO DANNI EOOD(VAT: BG207395566)가 제공합니다. Expense Budget Tracker는 Kirill Markin이 만들었습니다. [kirill-markin.com](https://kirill-markin.com/)은 제작자 본인의 웹사이트이며 이 제품 및 관련 프로젝트와 연결되어 있습니다.

## 사용자 데이터

사용자 데이터는 사용자의 소유입니다. 당사는 사용자가 입력한 재무 정보에 대해 어떠한 권리도 주장하지 않습니다. 사용자는 언제든지 자신의 데이터를 내보내거나 삭제할 수 있습니다.

## 외부 AI 클라이언트

OAuth를 통해 외부 AI 클라이언트에 MCP 서비스 이용 권한을 부여하면, 클라이언트의 선택과 부여한 접근 권한에 대한 책임은 사용자에게 있습니다. 클라이언트의 결과를 근거로 판단하거나 변경 사항을 적용하기 전에 그 결과를 검토할 책임도 사용자에게 있습니다. 클라이언트와 모델 제공업체는 각자의 약관에 따라 사용자가 요청한 데이터를 처리합니다. 당사는 외부 클라이언트의 작동이나 결과를 통제하지 않으며 이에 대한 책임을 지지 않습니다.

## 허용되는 이용 범위

서비스를 불법 활동에 이용하거나, 다른 사용자의 데이터에 접근을 시도하거나, API 요청 한도를 악용해서는 안 됩니다.

## 가용성

클라우드 서비스는 가능한 범위에서 제공됩니다. 가용성을 보장받아야 한다면 자체 인프라에서 앱을 직접 호스팅하세요.
