Quicken のファイルには、日々の入出金や投資の記録に加え、支払い予定、添付ファイル、税務用のカテゴリやレポートまでたまっていきます。画面の使いやすさだけで乗り換え先を選ぶと、普段の作業に必要なデータを移せないことがあります。続けたい作業を洗い出し、そのデータをどの形式で書き出せるかから確認しましょう。

ここで取り上げる **Quicken の代替ソフト** は、用途で選ぶと次のようになります。

- **Moneydance** は、デスクトップで家計全般を管理する使い方に最も近い候補です。
- **Monarch Money** は、金融機関の口座をまとめて確認できるダッシュボードを、運用の手間をかけずに使いたい家庭向けです。
- **GnuCash** は、複式簿記を使う、無料のオープンソース会計ソフトをデスクトップで使いたい人に向いています。
- **Actual Budget** は、ローカルデータを中心に封筒式予算管理をしたい人向けです。さまざまな取引ファイルを取り込め、外部サービス経由の銀行同期も選べます。
- **Expense Budget Tracker** は、明細を元の通貨のまま保存して確認できる台帳、共有ワークスペース、エージェントからのアクセスが必要な人向けです。銀行の自動同期には対応せず、内容を確認してから明細を取り込みます。

Quicken のすべての使い方を引き継げる候補はありません。まず用途別の表で候補を絞り、データを動かす前に形式別の対応表を確認してください。

## Quicken を使い続けるほうがよい場合

新しさやオープンソースであること、特定の条件で安いことだけで、乗り換えを決める必要はありません。[Quicken Classic（英語）](https://www.quicken.com/products/pricing-comparison-classic/) は現在も Windows または Mac にインストールして使う製品で、機能はプランと環境によって異なります。複数の機能を組み合わせて使う場合、長年の運用をそのまま置き換えるのは難しくなります。

次の機能が欠かせないなら、Quicken を継続するか、用途を絞って残してください。

- すでに安定して連携できている金融機関からの自動ダウンロード
- 証券の購入ロット、取得原価、ポートフォリオ分析、退職後の資金計画
- 税務向けのカテゴリとレポート
- [請求の管理や支払い（英語）](https://www.quicken.com/products/bill-manager/)
- 口座や取引と一緒に保存した添付ファイル
- 事業や賃貸物件に関する管理
- 使い慣れた定期取引、カスタムレポート、残高照合の手順
- こうした作業をまとめる パソコン上の 1 つのファイル

Quicken の Windows 版ガイドでは、[口座、ダウンロード、投資、予算、レポート、残高照合、添付ファイル、複数通貨（英語）](https://info.quicken.com/win/about-working-with-quicken) をまとめて扱っています。個々の製品が優れて見えても、そのファイルを連携のない 2～3 製品に分ければ、不便になることがあります。

## 5 つの候補でできることと制約

### Moneydance：デスクトップを中心に管理する

「Quicken に似たソフト」に求めているのが、デスクトップの取引台帳、定期取引、レポート、オンラインバンキング、複数通貨、投資管理なら、Moneydance が有力です。予算管理だけに絞らず、家計全般を扱えます。

移行面での利点は、[Quicken から出力したデータを QIF で取り込む手順（英語）](https://infinitekind.tenderapp.com/kb/importing-data-from-other-programs/importing-data-in-qif-format-2) が文書化されていることです。移行後にすべてがそのまま再現されるとは限りません。投資取引、分割取引、口座の通貨、資金移動、定期取引、期首残高はそれぞれ確認してください。

移行後の銀行データについて、Moneydance は [OFX Direct Connect、OFX/QFX/QIF の手動ダウンロード、CSV 取り込み、任意の Moneydance+ 口座集約サービス（英語）](https://infinitekind.tenderapp.com/kb/online-banking-and-bill-pay/downloads-methods) を案内しています。Direct Connect は銀行側の対応が必要です。Moneydance+ は任意のサブスクリプションで、通常の CSV インポーターは銀行から取得したファイル向けです。同社の [QIF 取り込み後のトラブル対処ガイド（英語）](https://infinitekind.tenderapp.com/kb/importing-data-from-other-programs/possible-problems-after-qif-import) では、期首残高、日付、資金移動の重複、過去の為替レートの欠落を確認項目として挙げています。

デスクトップを使い続け、Quicken の一体型の使い勝手をできるだけ保ちたいなら、Moneydance が向いています。運用を任せられる家計管理サービスを使いたい場合や、ブラウザからプログラムで操作できる台帳が欲しい場合には、ほかの候補が合います。

### Monarch Money：運用を任せられる家計ダッシュボード

Monarch は、自分でソフトを運用せずに、Web とモバイルのダッシュボードに口座をまとめたい人に向いています。口座集約サービス経由で金融機関に接続し、連携した保有資産や [手動入力した保有資産（英語）](https://help.monarch.com/hc/en-us/articles/10032888165140-Manual-Investment-Holdings) を管理できます。

公式に案内されている手動移行は CSV を使い、データの種類によって手順が異なります。[取引のインポート機能（英語）](https://help.monarch.com/hc/en-us/articles/4409682789908-Importing-Transactions-Manually) では、任意でカテゴリ、タグ、メモを指定できます。予算やキャッシュフローの集計額は取り込めません。[残高履歴は別の CSV で取り込みます（英語）](https://help.monarch.com/hc/en-us/articles/14882425704212-Importing-Account-Balances-Manually)。保有資産には有効な連携か手動設定が必要です。取引 CSV の取り込みを一括で取り消せないため、Monarch は小さなファイルで試すことを勧めています。

手元のデスクトップでデータを管理することより、口座連携や運用を任せられる家計画面を重視するなら、Monarch が候補です。取引 CSV で移るのは取引データで、Quicken ファイル全体は移行できません。

### GnuCash：オープンソースの会計ソフト

GnuCash は、複式簿記に慣れた人に向く **オープンソースの Quicken 代替ソフト** です。残高照合、定期取引、カスタマイズ可能なレポート、複数通貨の口座、投資口座に対応し、Windows、macOS、Linux で使えます。

この中では Quicken からの移行手順が明確で、[Quicken データ向けの QIF インポートアシスタント（英語）](https://www.gnucash.org/docs/v5/C/gnucash-manual/trans-import.html) が公式に案内されています。同じマニュアルに OFX/QFX と CSV の取引取り込みも記載されています。OFX/QFX と CSV は共通のインポーターで重複を照合します。QIF アシスタントには独自の確認手順と制限があります。使い方が変わるのは会計モデルです。カテゴリは収益・費用の勘定科目となり、振替は借方と貸方が釣り合う仕訳として記録します。柔軟に管理できる一方、帳簿を付ける人には会計の知識がより求められます。

無料でオープンソースのデスクトップ会計ソフトが必要なら、GnuCash が向いています。証券、重複処理、口座の対応付けなど、Quicken 固有の扱いが保たれているかは、データのコピーを使って QIF で試してください。

### Actual Budget：ローカル優先の封筒式予算管理

Actual Budget は封筒式予算管理とローカル優先のデータ設計が中心です。アプリは手元のデータで動作し、自分で選んだサーバー経由で同期できます。任意のエンドツーエンド暗号化を有効にすると、予算データは端末を出る前に暗号化されます。公式ドキュメントによると、手元の端末上のデータは暗号化されません。銀行同期を有効にした場合、連携サービスの認証情報は `actual-server` に保存され、予算データの暗号化の対象外です。

この中では Actual が最も多くの取引ファイル形式を公式に案内しています。[QIF、OFX、QFX、CSV、CAMT（英語）](https://actualbudget.org/docs/transactions/importing/) に対応します。任意の銀行連携では、北米の金融機関向けの SimpleFIN Bridge など、地域ごとのサービスを利用できます。[取引の取得（英語）](https://actualbudget.org/docs/advanced/bank-sync/) は手動で、バックグラウンドでは自動同期されません。

Quicken の投資、税務、請求管理より、ローカル優先の封筒式予算管理と柔軟な明細取り込みを重視するなら Actual が向いています。

### Expense Budget Tracker：台帳の中身を確かめながら管理する

Expense Budget Tracker は台帳の明細を元の通貨で保存し、表示や集計の際に、指定した集計通貨へ換算します。自分の口座間でお金を動かした場合も、専用の「資金移動」として記録できます。共有ワークスペース、ホスト型 [MCP コネクタ](/ja/docs/mcp-connector/)、直接接続できる Agent API、オープンソースのセルフホスト版を備えています。

銀行の自動同期や総合的な投資管理機能はなく、QDF、QXF、QIF の直接取り込みにも対応していません。取引は手動で入力するか、銀行やカード会社の明細をエージェントに渡し、取り込む行を確認して書き込みを承認します。[明細の取り込みガイド（英語）](/blog/how-to-import-bank-statements-into-an-expense-tracker/) で確認と残高照合の流れを、[銀行連携なしで使う家計管理アプリ（英語）](/blog/budget-app-without-bank-linking/) でプライバシーと管理の手間について説明しています。

台帳で取引を追えること、明細ごとの元の通貨を保持できること、共有ワークスペース、エージェントからの操作、セルフホスティングが必要なら、Expense Budget Tracker が候補になります。自分で運用する前に、[開発者向けセルフホスティングガイド（英語）](/blog/self-hosted-open-source-budget-tracker-for-developers/) を確認してください。

## Quicken の形式別に見る移行先

似た拡張子が並びます。**QDF** は Windows 版 Quicken Classic が作業に使うデータファイルです。**QXF** は Quicken Transfer Format、**QIF** は旧形式の Quicken Interchange Format です。**QFX** は OFX に関連する銀行取引の交換用ファイルで、QXF とは別です。

ここで比較した 5 つのソフトの公式インポート資料には、使用中の QDF ファイルから直接移行する手順は記載されていません。Quicken の現行 Windows 版の [QXF の説明（英語）](https://info.quicken.com/win/how-do-i-export-data-to-a-qxf-file) では、QXF は Quicken ファイル間の移行形式です。対象となる投資用・事業用以外の口座と、その取引、定期取引、カテゴリ、タグが含まれます。投資口座と事業用口座、予算、添付ファイル、レポート、アプリ設定は対象外です。

これは Windows 版 Quicken Classic のエクスポート仕様です。Mac 版 Quicken Classic ではメニューと利用できる形式が異なるため、移行方法を選ぶ前にインストール済みのバージョンで確認してください。

| Quicken または金融機関から取得するデータ | Moneydance | Monarch Money | GnuCash | Actual Budget | Expense Budget Tracker |
|---|---|---|---|---|---|
| 使用中の `.QDF` ファイル | [Quicken 固有のファイルは読み込めない（英語）](https://infinitekind.tenderapp.com/kb/importing-data-from-other-programs/importing-from-quicken-without-qif)。先に Quicken でエクスポート | 直接取り込みの記載なし | 直接取り込みの記載なし | 直接取り込みの記載なし | 直接取り込み非対応 |
| `.QXF` 転送ファイル | [QXF には非対応（英語）](https://infinitekind.tenderapp.com/kb/importing-data-from-other-programs/importing-from-quicken-without-qif)。利用可能なら QIF でエクスポート | 直接取り込みの記載なし。必要な履歴を CSV で再構成 | 直接取り込みの記載なし。QIF または取引ファイルを使用 | 直接取り込みの記載なし。QIF または取引ファイルを使用 | 直接取り込み非対応 |
| `.QIF` エクスポート | Quicken からの移行手順あり | 直接取り込みの記載なし。必要なデータを Monarch の CSV 形式に変換 | Quicken 用アシスタントの記載あり。口座と投資データを確認 | 取引取り込みの記載あり | 直接取り込み非対応。確認済みのレポートや明細データを使用 |
| Quicken のレポートを Excel に出力後、CSV として保存 | 完全移行は不可。家計ソフトの CSV には、銀行 CSV 用の通常手順に代えて [Text File Importer 拡張機能（英語）](https://infinitekind.tenderapp.com/kb/online-banking-and-bill-pay/importing-csv-files) を使用 | 取引 CSV を取り込み。残高履歴は別の CSV、保有資産も別途設定。予算は移行不可 | 取引 CSV。口座と列を対応付ける | 取引 CSV。フィールドを対応付ける | 内容を確認後、手動またはエージェントで入力。取引データを直接取り込む専用のアップロード機能はなし |
| 銀行やカード会社から新規に取得した明細 | OFX/QFX/QIF の直接取り込み。CSV は手動で項目を対応付ける | 取引 CSV。日付付き残高の CSV があれば別途取り込み | QIF、OFX/QFX、取引 CSV | QIF、OFX/QFX、CSV、CAMT | 手動またはエージェントで取り込み。取引データを直接取り込む専用のアップロード機能はなし |

Quicken の [エクスポートガイド（英語）](https://info.quicken.com/win/export-data-from-quicken) では QIF は旧式の移行形式とされ、レポートデータは Excel へ出力できます。移行先が CSV を要求する場合は、表計算ソフトで該当するシートを CSV として保存できます。得られるのは元のデータベースの一部をまとめたレポートです。取り込む前に、口座、日付、金額の符号、カテゴリ、資金移動の対応を確認しておく必要があります。

最初の試行では、長い Quicken レポートより、銀行やカード会社の新しい明細のほうが扱いやすいことが多いです。明細の期間が明確で、照合できる期末残高もあります。Quicken で編集した支払先、カテゴリ、メモを引き継ぐほうが重要なら、Quicken のレポートを使います。同じ口座の同じ期間に、両方のデータを取り込まないでください。

## 小さく試して、戻れる状態にしておく

移行先に取り消し操作がなくても、乗り換えの判断は後戻りできるようにしておきます。たとえば Monarch では、取引 CSV の取り込みをワンクリックで元に戻せません。

1. **Quicken をバックアップする。** 何かをエクスポートする前に、使用中の QDF ファイルを保存し、Quicken の通常のバックアップを作ります。試行中も Quicken を使える状態にしておきます。
2. **台帳以外の作業も洗い出す。** 連携口座、投資、定期取引、請求の処理、添付ファイル、税務レポート、カスタムレポート、通貨、事業や賃貸物件のデータを一覧にします。一つずつ移行先を決めるか、Quicken に残します。
3. **投資用以外の口座で、締め済みの期間を選ぶ。** 返金や資金移動を含む決済用口座やクレジットカードの明細なら、単純な取引だけの明細より多くのケースを確認できます。
4. **データ元を一つ選ぶ。** 一つの明細期間には、Quicken のエクスポートか金融機関の新しい明細のどちらかを使います。期首残高、期末残高、取引件数を控えます。
5. **試行専用の場所を用意する。** Moneydance や GnuCash の新規ファイル、テスト口座、Actual の別予算、Monarch の一時的な手動口座、Expense Budget Tracker の新規ワークスペースを使います。すでに運用している場所では試さないでください。
6. **少数の取引から取り込む。** 種類の異なる 10～20 件で、符号の反転、日付のずれ、支払先の欠落、カテゴリの問題、重複の扱いを確認できます。
7. **合計と取引の中身を確認する。** 符号、日付、通貨、分割取引、返金、資金移動を確認します。2 件の誤りが相殺されて、期末残高だけ合って見えることもあります。
8. **期間全体の残高を照合する。** 移行先の期末残高を選んだデータ元と突き合わせ、差があれば一つずつ原因を確認します。そのうえで、実際に使うレポートや予算画面を比較します。
9. **対象を増やす前に並行運用する。** Quicken ファイルを照合元として残し、別の期間でも試します。口座は一つずつ追加し、移行先での運用を確かめるまでは、投資、税務、添付ファイル、請求処理を Quicken に残します。

複数通貨を使っている場合は、試行に通貨の異なる口座間での実際の資金移動を 1 件入れてください。両口座それぞれの通貨での移動額と口座残高、手数料、集計通貨に換算した結果を確認します。[複数通貨で予算を管理するガイド（英語）](/blog/multi-currency-budgeting-for-expats/) では台帳の仕組みを詳しく説明しています。

## 用途別の選び方

デスクトップで Quicken に近い操作と文書化された QIF 移行手順を求めるなら Moneydance。口座の集約と家計ダッシュボードの運用を任せたいなら Monarch が候補です。オープンソースのデスクトップ会計と QIF の取り込みを重視するなら GnuCash、ローカル優先の封筒式予算管理と柔軟な取引取り込みなら Actual が向いています。

中身を確認できる台帳、元の通貨での記録、共有ワークスペース、プログラムからのアクセスが必要なら、Expense Budget Tracker が向いています。ご自身で操作する場合は [クラウド版アプリ](https://app.expense-budget-tracker.com/) から始められます。ターミナルや AI エージェントから始める場合は、[`https://app.expense-budget-tracker.com/api/agent`](https://app.expense-budget-tracker.com/api/agent) を使います。レスポンスには、その時点の Agent API のベース URL、認証の接続先、MCP エンドポイント、利用できるアクションが記載されています。

普段の作業を無理なく引き継げる候補を選んでください。乗り換え先で締め済みの 1 期間を再現し、台帳以外の作業もすべて移行先が決まるまでは、元の Quicken ファイルを残しておきましょう。
