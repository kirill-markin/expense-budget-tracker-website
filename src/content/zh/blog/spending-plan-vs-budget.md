**预算**和**支出计划**往往只是同一件事的两种叫法。[FDIC 的 Money Smart 资料](https://www.fdic.gov/system/files/2024-05/fdic-gr9-12-parentguide-module-2.pdf)明确指出，预算也叫支出计划。[Consumer.gov 对预算的解释同样务实](https://consumer.gov/your-money/making-budget)：一份写明每月如何花钱的计划。

不过，在日常个人理财中，这两个名称往往代表不同的详细程度。本文所说的**支出计划**，是较简略、更灵活的框架；**预算**则是按分类逐项细分的详细计划。这是两种实用做法，并非正式定义。

支出计划和预算怎么选？实用的判断标准是：选择能帮助你做决定的详细程度，并让所选方法始终与实际交易和账户余额挂钩。混合方法可以同时处理分类取舍和现金流时间安排，而不把它们混为一谈。

## 支出计划与预算：快速对比

这张表比较的是两种常见做法，并非两个正式独立的体系。

| 问题 | 简化支出计划 | 详细预算 |
| --- | --- | --- |
| 规划哪些内容？ | 收入、账单、预留资金，以及一笔总的灵活支出额度 | 收入，以及各个支出分类的计划金额 |
| 核心问题 | “安排好各项必要用途后，还有多少钱可以放心花？” | “钱应该花到哪里，哪些分类正在偏离计划？” |
| 通常复盘什么？ | 灵活支出总额和近期资金需求 | 各分类的计划金额与实际金额 |
| 更适合 | 只需大致总额即可的快速月度计划 | 需要在分类之间做取舍，或需要多人看清同一份分类明细的家庭 |
| 主要风险 | 一笔总额度可能掩盖超支来源 | 分类太多可能增加工作，却不能改善决策 |
| 能否纳入现金流时间安排？ | 可以 | 可以 |

名称本身不决定灵活性。详细预算可以设置缓冲资金和可调整的分类。如果每一笔钱都已安排好、没有变动余地，月度支出计划也可能很僵硬。

## 同一个月，三种看法

假设一个家庭每月收到两笔 $2,400 的工资，分别在 1 日和 15 日到账。月度税后收入共 $4,800，月初活期账户余额为 $900。

这 $900 不是本月的新收入。它之所以重要，是因为第二笔工资到账前已有账单到期。

### 1. 先决定各分类怎么分配

这个家庭先分配本月收入：

| 分组 | 分类 | 计划金额 |
| --- | --- | ---: |
| 固定账单 | 房租 | $1,500 |
| 固定账单 | 水电等公共事业费 | $250 |
| 固定账单 | 保险 | $200 |
| 固定账单 | 电话和网络 | $100 |
| 固定账单 | 托儿费用 | $650 |
|  | **固定账单小计** | **$2,700** |
| 灵活支出 | 食品采购 | $600 |
| 灵活支出 | 交通 | $240 |
| 灵活支出 | 外出就餐和娱乐 | $300 |
| 灵活支出 | 家庭和个人开支 | $160 |
|  | **灵活支出小计** | **$1,300** |
| 储蓄和预留资金 | 应急储蓄 | $300 |
| 储蓄和预留资金 | 不定期开支备用金 | $200 |
|  | **储蓄和预留资金小计** | **$500** |
| 缓冲资金 | 留在活期账户中，暂不分配 | $300 |
|  | **已分配收入合计** | **$4,800** |

计算如下：

**$4,800 收入 − $2,700 固定账单 − $1,300 灵活支出 − $500 储蓄和预留资金 = $300 缓冲资金**

简化支出计划可以只保留上面三项加粗小计和缓冲资金。详细预算则保留各个分类，因为之后可能需要分别对食品采购、交通和外出就餐做不同取舍。

### 2. 再看现金流时间安排

按月计算，收支能够平衡，但这不代表活期账户每周都有足够余额。**现金流预算**关注的正是时间安排。[CFPB 的现金流预算工具](https://files.consumerfinance.gov/f/documents/cfpb_your-money-your-goals_cash_flow_budget_tool_2018-11_ADA.pdf)按周跟踪资金，并将每周期末余额带入下一周。

下面是这个家庭计划的时间安排：

| 周 | 活期账户期初余额 | 收入 | 固定账单 | 灵活支出 | 转入储蓄 | 活期账户期末余额 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | $900 | $2,400 | $1,600 | $325 | $0 | $1,375 |
| 2 | $1,375 | $0 | $450 | $325 | $0 | $600 |
| 3 | $600 | $2,400 | $650 | $325 | $500 | $1,525 |
| 4 | $1,525 | $0 | $0 | $325 | $0 | $1,200 |

第 1 周要支付房租、电话和网络账单。第 2 周要支付水电等公共事业费和保险。第 3 周要支付托儿费用，第二笔工资也在这一周到账。

把 $500 从活期账户转入一个正在跟踪的储蓄账户，属于内部转账。它会让活期账户余额减少、储蓄账户余额增加相同金额，因此应列入现金流时间表，但不应计为 $500 的家庭支出。应急储蓄和不定期开支备用金仍是事先安排好的预算额度，只是它们回答的问题与支出统计不同。[银行转账算支出吗？](/zh/blog/do-bank-transfers-count-as-expenses/)更详细地介绍了其中的边界情况。

如果月度总额看起来宽裕，但某个中间余额接近零，就应提前调整账单到期日、转账日期、灵活支出节奏或期初缓冲资金。如果难点在时间安排，[账单日历](/zh/blog/how-to-use-a-bill-calendar-for-budgeting/)会很有帮助。

### 3. 最后比较计划与实际

月底，这个家庭根据已入账交易完成结算：

| 分类 | 计划金额 | 实际金额 | 实际减计划 |
| --- | ---: | ---: | ---: |
| 房租 | $1,500 | $1,500 | $0 |
| 水电等公共事业费 | $250 | $270 | +$20 |
| 保险 | $200 | $200 | $0 |
| 电话和网络 | $100 | $100 | $0 |
| 托儿费用 | $650 | $650 | $0 |
| **固定账单小计** | **$2,700** | **$2,720** | **+$20** |
| 食品采购 | $600 | $640 | +$40 |
| 交通 | $240 | $190 | −$50 |
| 外出就餐和娱乐 | $300 | $360 | +$60 |
| 家庭和个人开支 | $160 | $130 | −$30 |
| **灵活支出小计** | **$1,300** | **$1,320** | **+$20** |
| **总支出** | **$4,000** | **$4,040** | **+$40** |

储蓄转账仍按计划足额完成。因此，本月剩余缓冲资金为：

**$4,800 收入 − $4,040 支出 − $500 储蓄和预留资金 = $260**

活期账户月末余额应为：

**$900 期初余额 + $4,800 收入 − $4,040 支出 − $500 转账 = $1,160**

这比计划的 $1,200 期末余额低 $40，正好等于净超支额。正在跟踪的储蓄账户余额增加了 $500；转账只是改变了资金所在账户，没有改变家庭总支出。

这正是**预算与实际对比**的价值。食品采购和外出就餐超出计划，但交通以及家庭和个人开支抵消了部分差额。现在，这个家庭可以判断是否需要为某个分类制定新计划，而不用把每一项偏差都当作失败。

## 该用哪一种？

### 大致总额够用时，选择简化支出计划

简化计划适合以下情况：

- 收入和固定账单可以预测
- 一笔灵活支出额度已经足以提供指引
- 增加分类细节不会改变决定
- 主要问题是让本月收支平衡

这里的灵活预算，意味着不用维护太多假设，月内情况变化时也有空间调配资金。但还是要跟踪交易，否则剩余的灵活支出额度只是猜测。

### 分类会影响决定时，采用详细分类预算

以下情况值得增加细节：

- 食品采购、外出就餐、交通或其他分类需要单独限额
- 不定期开支需要明确的月度分配
- 两人或更多人需要看到同一套分类数据
- 你想解释为什么会反复超支

分类清单要足够精简，方便复盘。“饮食”这个大类起初也许够用；等食品采购和餐厅消费开始需要不同决策时，再把它拆开。

### 时间安排和分类控制都重要时，采用混合方法

混合方法包括：

1. 按分类制定的月度计划
2. 按周查看的现金流
3. 实际交易和账户余额
4. 月末的计划与实际复盘

如果工资到账日和账单到期日安排得不巧，或资金会在多个账户间流动，这种方法尤其有用。上面的示例就是混合方法：分类用来指导决策，周度表格则避免月度总额看似充足、实际却在中途缺钱。

## 建立一套本月就能运行的系统

1. **划定范围。** 列出纳入计划的活期账户、储蓄账户、现金和银行卡，并记下各自当前余额。
2. **使用交易记录，不要依赖记忆。** 查看近期收入、账单和可变支出。在设定金额前，[支出审计](/zh/blog/how-to-do-a-spending-audit/)可以找出遗漏的分类和失真的平均值。
3. **先规划可靠收入和必须支付的账单。** 不仅要写月度总额，也要写日期。
4. **分配储蓄和预留资金。** 确定金额和用途。如果两个账户都在跟踪范围内，应将资金变动记录为转账，而不是支出。
5. **分类只细化到有用的程度。** 先从一笔总的灵活支出额度开始。只有当单独设定金额会改变你的做法时，才继续拆分。
6. **按周预测余额。** 将每周期末余额带入下一周，并检查最低点，而不只是月末最后一天。
7. **在月内记录实际交易。** Consumer.gov 的预算流程遵循相同的基本循环：月初制定计划、记录支出、月末比较结果，再用结果规划下个月。
8. **核对账目后再修改。** 确认账本与银行和银行卡的已入账记录一致，再按分类比较计划金额和实际金额。如果余额对不上，先按照[预算与银行余额核对流程](/zh/blog/how-to-reconcile-your-budget-with-your-bank-balance/)处理，再修改计划。

顺序很重要。如果分类分析建立在遗漏交易或重复计算转账的基础上，看起来可能很精确，结果仍可能出错。

## Expense Budget Tracker 如何支持这套方法

[Expense Budget Tracker 的功能](/zh/features/)支持混合流程，但不会替你决定计划要细到什么程度。月度预算网格把收入和支出分类与计划金额、实际金额及差额放在一起。账本按账户生成逐笔余额；自有账户之间的转账会作为独立转账处理，而不会算作额外支出。

家庭需要时，可以使用多币种账户和共享工作区。这些功能不能替你做每月的预算决策；它们把分类计划、交易、转账和余额放在一起，方便相互核对。

## 做好每月收尾

无论叫什么，每月都用同样方式收尾：记录实际发生的情况，核对余额，比较计划和实际结果，只调整那些经实际验证并不合理的数字。这样，两种方法都不再只是一次性表格，而会成为一套下个月还能继续运行的系统。
