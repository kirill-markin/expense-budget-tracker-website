假设你把一台旧相机卖了 $120，银行账户却只收到 $102。你还花了 $3 买包装材料。扣完这些费用，这笔交易让家里的资金净增加 $99。预算需要反映的就是这个金额。

卖二手物品的账，可以从实际收款记起，再记下另行支付的费用，用一份简单的出售明细说明售价和到账金额为什么不同。设一个“出售个人物品”分类，就能把偶尔卖闲置的收款与工资分开。如果账本里也有平台账户，就先把交易记在这个账户下，之后平台向银行打款时，再记一笔转账。

![旧布料被裁成可用的布片，剪下的边角料放在一旁](/blog/how-to-track-money-from-selling-used-items.png)

## 从售价一路核对到银行到账

下面是这台相机的完整交易明细。金额都是假设的，不代表某个平台的定价或费率。

| 交易项目 | 金额 | 资金去向 |
| --- | --- | --- |
| 相机售价 | $120 | 计入平台余额 |
| 买家支付的运费 | $8 | 计入平台余额 |
| 销售手续费 | −$18 | 平台扣除 |
| 邮寄面单费用 | −$8 | 从平台余额中扣除 |
| 银行到账 | **$102** | 平台转入你的银行账户 |
| 包装材料 | −$3 | 通过银行账户另行支付 |
| 扣除这些费用后，家庭资金净增加额 | **$99** | 收到 $102，减去支付的 $3 |

这个例子中，买家总共支付了 $128。平台转给你的金额是 **$120 + $8 − $18 − $8 = $102**。扣除包装费后，你实际留下 $99。不过，包装费是你另外支付的，不应该列在平台扣款里。

具体扣了哪些费用，要看交易报告。银行流水只显示入账金额，不会说明这笔钱是怎么算出来的。例如，[eBay 的对账指南](https://www.ebay.com/help/selling/fees-credits-invoices/reconciling-ebay-sales-transactions?id=4847)介绍了包含交易、费用和打款信息的报告。

## 选一种记法，并保持一致

下面两种方法都能准确记录家庭资金增加 $99 的结果。同一笔交易选定一种记法，就始终按它来记。混用两种方法，很容易把费用扣两遍，或把平台打款又算成一笔出售收入。

### 只记录银行账户

把 **$102 的收款**记入“出售个人物品”，把 **$3 的包装费**记为出售费用。相机售价 $120、买家支付的运费 $8、手续费 $18 和邮寄面单费用 $8，则保留在出售明细里，方便核对。

平台扣除的手续费和邮寄面单费用已经从到账金额中减掉了。再把它们记成银行支出，账面余额就会偏低。如果在到账款之外另记一笔 $120 的出售收入，余额又会偏高。

偶尔卖几件东西，这样通常就够了：预算里能看到实际收款和你自己支付的费用。需要查看销售总额或平台扣费时，出售明细里也有记录。

### 同时记录平台账户

如果你想跟踪还留在平台上的钱，就先在平台账户里记录资金变动，再记平台打款：

| 账户 | 记录项目 | 金额 |
| --- | --- | --- |
| 平台 | 出售相机 | +$120 |
| 平台 | 买家支付的运费 | +$8 |
| 平台 | 销售手续费 | −$18 |
| 平台 | 邮寄面单费用 | −$8 |
| 平台 | 转入银行 | −$102 |
| 银行 | 平台转入 | +$102 |
| 银行 | 购买包装材料 | −$3 |

如果平台账户期初余额为零，也没有其他交易，最后余额就会回到零。银行账户的余额增加 $99。把两个账户合起来看，交易收款 $128 减去出售费用 $29，同样剩下 $99。

平台打款属于[账本内自有账户之间的转账](/zh/blog/do-bank-transfers-count-as-expenses/)。出售款项已经在平台账户里记过了，再把银行收到的 $102 归为收入，就会重复计算。手动录入或导入银行流水时，要将这笔入账与对应的转账匹配。

如果有多笔交易等着平台打款，或你想在预算里直接查看手续费，单独记录平台账户会有帮助。不过，你也需要多核对一个账户的余额。如果这些细节对你没什么用，只记录银行账户就可以。

## 留一份简单的出售明细

银行流水没写清的细节，可以放在笔记或电子表格里。一件物品占一行，相关的平台报告也一起保存。

| 字段 | 相机示例 |
| --- | --- |
| 物品与订单编号 | 二手相机，订单 C-104 |
| 出售日期与状态 | 9 月 19 日；等待打款 |
| 物品售价与买家运费 | $120 + $8 |
| 平台扣除的手续费与邮寄面单费用 | $18 + $8 |
| 另行支付的费用 | 包装材料 $3，附银行付款流水号 |
| 预计到账 | $102 |
| 打款编号、日期与金额 | 收到后填写 |
| 原始购买记录 | 收据，或其他能证明当初购买成本的材料 |

如果平台一次打款包含多笔交易，就在对应的各行填上同一个打款编号。计入账单上的其他调整后，这些交易的净额合计应该与到账金额相符。有差额就要找到原因：可能是退款、后来扣的邮寄面单费用，或另一笔手续费。把调整单独写清楚，不要随手记一笔“其他”来凑平数字。

## 等钱可用后，再安排支出

物品已经上架、价格已经谈妥，都不意味着这笔钱可以纳入可用预算。即使买家已经付款，平台也可能暂扣款项：[eBay 关于交易款项暂扣的说明](https://www.ebay.com/help/selling/getting-paid/getting-paid-items-youve-sold/payments-hold?id=4816)指出，暂扣期间，款项还不能转给卖家。

如果只记录银行账户，就在出售明细中将交易标为待到账，等钱进入银行再记账。如果还记录平台账户，就根据账单核对平台余额，同时从可支配金额中排除暂扣资金。如果你的预算工具无法清楚区分这两类金额，就使用出售明细，只记录银行账户。

当面收现金时，在买家付款后把收款记入现金账户。之后把这笔现金存进已纳入记账的银行账户，属于转账。[现金支出记录指南](/zh/blog/how-to-track-cash-expenses/)介绍了如何核对现金账户余额。

## 给这笔一次性收款安排用途

把卖闲置收到的钱放进“出售个人物品”分类，查看时就能将它与工资区分开。除非有明确理由预计下个月还会收到类似款项，否则这个分类下个月的计划收入就设为零。卖掉一台相机，并不意味着每月都有更多稳定收入。

例子中，扣除出售费用后还剩 $99。你可以留出 $70 用于购买替代品，另外 $29 用于其他家庭开销。分配用途本身不算交易；把这 $70 转入已纳入记账的储蓄账户，才是一笔转账。等真正买下替代品时，再记录支出。

当初买入和后来卖出，应当各自保留一笔记录。拿今天的出售款项去冲减几年前的购买支出，会让花钱和收钱的时间变得不清楚。

## 如果需要给买家退款

保留原始出售记录，再添加实际退款和相关调整。如果只记录银行账户，就把从银行扣除的退款记在同一个“出售个人物品”分类下。如果平台从后续打款中扣除退款，就在出售明细里说明那次到账金额为什么变少。这种情况下，银行没有单独扣款，也就不需要再记一笔银行支出。

如果账本里也有平台账户，就按照账单，把退款以及退回的手续费或运费记在平台账户下。只有实际发生单独的银行扣款时，才另记一笔。退款时，手续费不一定会退还，所以应以实际金额为准，不要把原始记录全部反向记一遍。更新这件物品最终的净收款，并相应调减此前用这笔钱安排的预算。

## 出售所得和应税利润不是一回事

例子中的 $99 表示扣除出售费用后增加的资金。它不代表卖相机的利润，因为我们还没有算入当初买相机花的钱。买家的付款总额和银行净到账金额，都不能单独回答是否需要纳税的问题。

对于美国纳税人，[美国国税局（IRS）关于出售个人物品的说明](https://www.irs.gov/businesses/what-to-do-with-form-1099-k)区分了亏本出售和获利出售：个人物品的出售损失不能用于税前扣除，出售收益则需要纳税。保留原始购买凭证和出售记录；税务上怎么处理，并不取决于你在预算里给这笔钱取了什么分类名称。美国以外的读者，应查阅当地税务机关的规定。

这套方法适用于偶尔出售原本自用的物品。如果你是进货后再转卖，就需要适合这类经营活动的记录方式；可以先看[如何分开记录个人与业务收支](/zh/blog/how-to-separate-business-and-personal-expenses/)。

下次卖东西时，保存打款明细，选一种方法记账，再把账户余额与账单核对。核对一致后，你就知道这笔交易到底给家里留下了多少钱。
