## 先回答仪表盘这个问题

搜索 **Monarch Money 仪表盘替代方案**的人，通常不是想再找一份交易列表，而是想在一个地方看清几个经常出现的问题：

- 这个月我们花了多少钱？
- 有没有哪个分类超预算？
- 我们现在的净资产是多少？
- 哪个账户发生了变化？
- 最近是否有周期性账单要扣款？

Monarch 正是围绕这种总览体验设计的。它的[仪表盘由可移除、可调整顺序的小组件组成](https://help.monarch.com/hc/en-us/articles/360058127551-Customizing-Your-Dashboard)，包括预算、净资产、周期性交易、支出趋势、交易、投资和其他汇总。网页端和移动端的布局可以分别设置。如果你希望打开应用就能浏览完整的财务状况，不想自己搭建整套系统，这是一个很实际的优势。

Expense Budget Tracker 的仪表盘更聚焦，主要展示支出构成、余额随时间的变化和汇率波动的影响。日常操作更多集中在预算表和总账里。它不像现成的财务总览首页那么全面，但如果你希望从图表一路追溯到背后的账户和交易，这种设计很有用。

单看 **Monarch Money 预算仪表盘**这一需求，Monarch 的现成界面更全面。如果你要求仪表盘建立在一套可查验、可查询的数据模型之上，Expense Budget Tracker 更合适。

## 两种预算模型解决的是不同问题

Monarch 支持[分类预算和 Flex 预算](https://help.monarch.com/hc/en-us/articles/360048883631-Understanding-Your-Budget-in-Monarch)。分类预算会为每个支出分类单独制定计划。Monarch 默认采用的 Flex 预算，则把较难预测的支出归入一个更高层级的灵活额度。两种方式都基于月度现金流：把预计收入分配给支出和储蓄。

如果你希望由应用引导着完成每月规划，这套方式很好用。Monarch 会参考过去六个月各分类的支出，自动填好第一份预算，你之后可以再调整金额。网页端的预算界面也会显示预算、实际和剩余三列，因此两款产品的差异不在于数字是否明确展示，而在于这些数字如何组织。

Expense Budget Tracker 走的是更直接的路线。月度预算表把每个分类的计划、实际和差额并列显示，并为预算变更保留只能追加、不能改写的审计记录。预算与总账始终紧密相连。如果你已经知道自己想怎样规划，主要需要系统清楚显示实际结果偏离计划多少，这种方式很合适。

可以按你希望软件怎样帮你做预算来选：

- 如果你想要分类预算或 Flex 预算、自动计算的初始计划和可选的结转功能，选择 Monarch。
- 如果你想要固定的计划与实际对照表、由总账计算的实际金额和预算变更历史，选择 Expense Budget Tracker。

## 净资产：精致报表，还是总账可追溯性

**Monarch Money 净资产仪表盘**把账户汇总与独立的净资产视图结合起来。Monarch 还提供支出、现金流和投资报表，因此它可以承担家庭财务总览的角色，而不只是用来做预算。

它较新的长期规划功能走得更远。[Monarch 的预测功能](https://help.monarch.com/hc/en-us/articles/48344305092244-Forecasting-in-Monarch)会根据账户数据、支出历史、假设和人生事件，推算未来的净资产与现金流。这项功能属于 Monarch Plus 套餐。套餐内容可能调整，因此请以 Monarch 的[当前定价页面](https://www.monarch.com/pricing)为准，不要依赖对比文章中可能已经过时的价格。

Expense Budget Tracker 并不打算复刻这整套规划界面。它从更基础的数据层做起：账户的滚动余额由总账记录计算得出，自己名下账户之间的转账会保留为独立记录，总额则可以按选定的报表币种查看。余额变化图再展示整体财务状况怎样随时间变化。

这个取舍很容易被忽略。Monarch 开箱即用，净资产相关功能更丰富。Expense Budget Tracker 则让你更容易从报表中的余额追溯到底层总账。如果独立的净资产功能是你寻找新工具的主要原因，可以阅读更聚焦的[开源净资产追踪器与电子表格对比](/zh/blog/net-worth-tracker-open-source-spreadsheet-alternative/)。

## 导入不等于对账

Monarch 的核心使用方式是连接账户。它的[入门指南](https://help.monarch.com/hc/en-us/articles/360048393272-Getting-Started-with-Monarch)建议用户连接账户，让余额和交易通过数据提供商进入系统。Monarch 也支持把 [CSV 交易记录导入](https://help.monarch.com/hc/en-us/articles/4409682789908-Import-Transaction-Data-Manually-from-Banks-or-Other-Finance-Apps)已同步或手动创建的账户，还可以单独导入余额历史，补齐以往的数据缺口。

导入不等于对账，这个区别很重要。Monarch 允许手动创建交易，但它的[手动交易文档](https://help.monarch.com/hc/en-us/articles/360058441811-Creating-Manual-Transactions)明确说明，产品没有对账功能。如果相应的银行交易随后同步进来，Monarch 不会自动删除之前手动录入的记录。在已同步账户中添加一笔手动交易，也不会改变该账户的余额。

这并不意味着 Monarch 不值得用，只是说明在迁移多年的历史数据之前，应该先测试自己的实际流程。账户连接带来的自动数据流很方便，但 CSV 导入和手动记录仍然需要检查。

Expense Budget Tracker 不会自动同步银行账户。数据只能通过手动录入，或由用户主动发起的导入流程进入系统。它的 AI 智能体可以读取银行账单或信用卡导出文件，调用工作区已有的账户和分类，通过 API 写入交易，并协助核对导入后的余额与账单是否一致。智能体写入的内容仍需由你审核。

这比被动同步更费心，但数据进入系统的边界也更清楚：不会因为某个连接抓取到了数据，就自动出现新记录。如果你想要的正是这种工作方式，可以阅读完整的[将银行账单导入支出追踪器指南](/zh/blog/how-to-import-bank-statements-into-an-expense-tracker/)，或查看[不连接银行账户的预算应用对比](/zh/blog/budget-app-without-bank-linking/)。

## Monarch 的家庭共享使用统一视图

Monarch 的家庭共享模式很明确。根据它的[入门指南](https://help.monarch.com/hc/en-us/articles/360048393272-Getting-Started-with-Monarch)，每位家庭成员都有独立账号，但所有人看到的是同一组账户、交易和同一份预算。每位成员都能看到全部内容，无法只对某位家庭成员隐藏特定账户。

对于想共用一份完整家庭财务视图的伴侣来说，这很方便，也不会出现一方看到的预算不完整的情况。按归属筛选可以在同一份数据中区分个人和共同收支，但不能让某个账户只对部分成员可见。

Expense Budget Tracker 以工作区来组织协作。用户可以拥有个人工作区、加入共享工作区，也可以为其他用途另建工作区。每个工作区都有自己的总账、预算和仪表盘。如果“家庭”并不是你唯一需要划分的边界，例如个人财务和共同财务不应放在同一份数据里，这种模式会很有用。

无论采用哪种模式，家庭成员都需要先讲清楚谁能看到什么。Monarch 默认让所有家庭成员看到全部内容，Expense Budget Tracker 则以工作区划定边界。如果想看更侧重共同规划的对比，可以阅读[最适合情侣的预算应用](/zh/blog/best-budget-app-for-couples/)。

## 多币种支持揭示了最大的结构差异

这是选择其中一款产品最明确的理由。

Monarch 的官方[货币文档](https://help.monarch.com/hc/en-us/articles/360048393552-International-Accounts-and-Currency)说明，产品在底层不会区分币种，也不会进行货币换算。因此，把不同币种的账户汇总在一起，可能得到误导性的总额。一个 10,000 美元的账户和一个 10,000 加元的账户，可能显示为合计“$20,000”，尽管两者价值并不相等。

Expense Budget Tracker 采用了不同的设计：

1. 每个账户都有自己的原币种。
2. 每笔交易都保留交易发生时的币种和金额。
3. 读取数据、生成报表时才按汇率换算。
4. 汇率波动的影响可以单独查看，不会被改写后的历史金额掩盖。

对于工资以美元发放、房租以欧元支付、储蓄以英镑持有的家庭，这个顺序很重要。总账保留交易当时真实发生的金额，仪表盘再根据当前查看需求换算。Expense Budget Tracker 账户之间的转账会作为独立、明确的总账记录保存。Monarch 对内部转账的处理方式不同：它使用转账分类，并将这类交易排除在预算和现金流之外。

如果日常生活涉及多种货币，Expense Budget Tracker 是更合适的**多币种预算应用**。更详细的分析可以阅读[外籍人士多币种预算指南](/zh/blog/multi-currency-budgeting-for-expats/)。

## 数据掌控改变了“自动化”的含义

Monarch 自动化的是面向普通用户的流程：连接金融机构、接收交易、自动分类，再查看系统整理好的仪表盘。这正是大多数人想要的自动化，能省去大量重复操作。

Expense Budget Tracker 则通过明确、可查验的程序接口实现自动化。它提供：

- 权限受限的 SQL API，并由工作区级行级安全策略提供保护
- 一套自助发现与接入流程，让 Claude Code、Codex、OpenClaw 或其他有能力的智能体在完成邮件验证后自行建立连接
- 可访问用户财务数据的 AI 对话
- 公开的数据模式和 API 规范
- 基于 Postgres 和 Docker Compose 的自托管方案

凭借这些能力，对于希望让脚本、智能体或自有基础设施参与财务流程的人来说，它是一款合适的**开源 Monarch Money 替代方案**。[源代码已在 GitHub 上公开](https://github.com/kirill-markin/expense-budget-tracker)。当然，它也要求用户承担更多责任：API 密钥必须妥善保存，智能体写入的变更需要审核，自托管则意味着要由你自己运维服务。

你不需要自托管也能使用它。[托管版应用](https://app.expense-budget-tracker.com/)是最快的上手方式，[入门指南](/zh/docs/getting-started/)则同时介绍托管和自托管两种路径。[功能页面](/zh/features/)展示了产品目前的功能范围。

## 哪些人应该继续使用 Monarch Money？

如果下面大多数描述都符合你的需求，继续使用 Monarch：

- 你希望连接银行后，由数据源持续把交易同步进系统。
- 你更看重精致的网页端和移动端仪表盘，而不是直接访问数据模型。
- 你想在一款消费级应用里同时管理预算、目标、周期性交易、投资和净资产。
- 你的家庭可以接受每位成员看到所有已连接的账户。
- 你的财务情况适合 Monarch 的货币模型。
- 你希望由产品厂商运维整套系统。

更换工具总会带来额外工作。如果 Monarch 已经提供了你信任的仪表盘，而你不需要多币种换算、API 访问或自托管，继续使用它很合理。

## 哪些人应该改用 Expense Budget Tracker？

如果下面几项对你来说不可妥协，Expense Budget Tracker 更合适：

- 你希望图表背后有一份可查验的总账。
- 相比长期连接银行，你更喜欢手动导入或由智能体协助导入账单。
- 转账必须在余额模型中保留为独立事件。
- 你使用明确的计划、实际和差额来做预算。
- 多种原币种需要共存，不能被压成一个没有币种区别的金额。
- 你希望通过有文档说明的 SQL API 查询或更新数据。
- 你需要共享工作区或一款**自托管 Monarch Money 替代方案**。

取舍确实存在：你会放弃一部分 Monarch 精致而全面的仪表盘体验，并为数据录入、审核乃至基础设施承担更多责任。换来的是一套更容易查验，也更便于通过程序操作的系统。

## 用低风险方式做决定

不要一开始就迁移所有数据。先测试最有可能暴露不匹配的那部分财务数据。

1. 选择一个有完整月份日常流水的活期账户或信用卡账户。
2. 从银行导出一份 CSV 账单。
3. 在 Expense Budget Tracker 中添加这个账户、账户的原币种和一小组分类。
4. 按照文档中的接入流程连接智能体，或手动录入少量样本。
5. 检查导入后的分类和转账处理；如果样本无误，再加入这个月的其余数据。
6. 将期末余额、预算实际金额和仪表盘总额，分别与银行账单及 Monarch 中的数据对比。

这项测试比功能清单更能说明问题。你会知道主动导入让你更安心还是觉得麻烦，月度预算表是否适合自己的规划方式，以及访问总账对你是否真的有用。

## 常见问题

### 与 Monarch Money 最接近的开源替代方案是什么？

Expense Budget Tracker 涵盖预算、余额、仪表盘、共享工作区、多币种报表、AI 对话、API 和自托管。它不会照搬 Monarch 的界面，也没有相同的银行账户连接流程。选择它，是为了掌控总账和基础设施，而不是寻找一个与 Monarch 逐像素一致的复刻版本。

### Expense Budget Tracker 会自动同步银行账户吗？

不会。它支持手动录入，也支持连接 AI 智能体后导入账单，但不提供银行账户自动同步。这项差异应该成为决策的一部分，而不是藏在小字里。

### Monarch Money 可以导入 CSV 文件吗？

可以。Monarch 支持通过 CSV 导入交易和账户余额历史。文件结构、必填字段、重复项处理和账户分配仍然很重要，因此你应该检查导入结果，不能把上传文件当成已经完成对账。

### 哪一种方案更适合追踪净资产？

如果你想在一个由厂商托管的界面里获得独立的净资产仪表盘、投资相关信息和可选的长期预测，选择 Monarch。如果你希望账户余额来自可查验的总账，并且需要跨多种货币生成报表，同时保留底层的原始金额，选择 Expense Budget Tracker。

### 情侣可以使用这两款产品吗？

可以，但共享模型不同。Monarch 为家庭成员提供独立登录账号，让所有人完整查看同一份家庭财务图景和同一份预算。Expense Budget Tracker 使用工作区，可以将个人和共同财务场景分开。

## 应该选择哪一款？

如果你想要一个精致、可以连接银行账户的仪表盘，开箱即用地覆盖预算、净资产、投资、周期性交易和报表，选择 Monarch。你也许根本不需要更换工具。

如果你更看重原币种数据、由总账计算的余额、可控导入、可编程访问或自托管，选择 Expense Budget Tracker。它无意复制 Monarch 的功能广度，而是让你更直接地掌控财务数据的底层运作。

如果这样的取舍符合你的需求，可以[打开 Expense Budget Tracker](https://app.expense-budget-tracker.com/)，先用一个真实账户进行测试，再决定是否迁移其余数据。
