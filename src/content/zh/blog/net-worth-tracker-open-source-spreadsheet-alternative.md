净资产总额即使算术上完全正确，也可能没有参考价值。漏了一张信用卡对账单、券商账户市值没有更新，或者转账少记了一边，一个看起来干净利落的数字就会失真。

当一个家庭的现金、债务和投资还分散在不同币种时，出错的风险会更高。解决办法未必是让应用自动连接银行。只要工作流程能让每笔余额都有来源，也能看出哪些账户太久没有更新，你就可以搭建一套可靠的**无需连接银行的净资产追踪器**。

Expense Budget Tracker 可以承担其中的账本和账户余额部分，但它的功能范围比完整的财富管理平台更窄。

![无需连接银行的多币种净资产追踪器，将现金、债务和投资账户分组以供核查](/blog/net-worth-tracker-without-bank-linking.png)

## 先弄清楚你要搭建的是什么

基本定义很简单：**净资产等于资产减去负债**。美国消费者金融保护局的 [Your Money, Your Goals 工具包](https://files.consumerfinance.gov/f/201504_cfpb_ymyg_toolkit-workers.pdf)也采用这一计算方式。

专门的净资产产品通常从资产清单开始。你添加银行账户、房产、汽车、贷款，也许还有单项投资，再不断更新它们的当前价值。Expense Budget Tracker 的起点不同：它从账本开始。这里没有单独的字段供你直接填写房产或汽车估值。

Balances 视图会汇总每个账户的账本记录。只有账本中出现活动后，账户才会显示出来；页面背后没有另一份手工维护的资产清单。账户及其交易会保留原币种，当前余额也可以根据每日外汇数据换算为一种报告币种。

满足以下条件时，合并余额才适合作为净资产视图：

- 你要纳入的每个现金账户、债务账户和手动估值的投资账户都已存在于账本中
- 正余额代表资产，负余额代表负债
- 自有账户之间的资金移动记为转账，而不是收入或支出
- 近期流水和手动估值都已经核对
- 每种货币都有可用的换算汇率

这并不会让产品变成通用的财富追踪器。它的边界很清楚：

| Expense Budget Tracker 擅长的事 | 目前不提供的功能 |
| --- | --- |
| 根据账本计算现金、信用卡、贷款及其他交易账户的余额 | 自动同步银行，或连接网银凭据 |
| 保留账户原币种，同时用一种报告币种统一查看 | 细化到单只证券的持仓，或券商数据源 |
| 将手动维护的账户总额归入普通组或投资组 | 股票、基金、加密资产或其他投资的实时定价 |
| 按币种、流动性和账户组查看正余额与负余额总计 | 房产估值数据源 |
| 余额历史、预算管理和交易对账 | 专门的目标规划或 FIRE 模拟器 |

如果你主要想查看当前的现金和债务余额，并为每个投资账户手动维护一个总额，这套方案很合适。如果你需要资产配置、计税批次、收益归因或实时持仓数据，就应该搭配一款专门的投资组合工具。

## 按真实对账单设置账户

先决定哪些账户要计入家庭总额。一份实用的清单可以包括：

- 活期、储蓄和现金账户
- 信用卡和信用额度
- 能够持续更新当前余额的贷款
- 按券商、养老金管理机构或其他投资服务商各设一个账户，手动维护其总额

为合并视图选择一种报告币种。住在西班牙的外籍居民，即使收入或储蓄使用 USD，也可以选择 EUR。未来大部分支出以 GBP 计价的家庭，则可以选择 GBP。这个选择只影响汇总结果的显示方式，不会改写账本记录的原币种。

接下来，通过账本活动创建账户。Expense Budget Tracker 根据账本记录生成账户列表，所以第一笔导入的交易或补录的期初记录会建立该账户。账户中的每笔记录都应使用它实际采用的原币种。如果还没决定如何导入，可以参考[银行对账单导入流程](/zh/blog/how-to-import-bank-statements-into-an-expense-tracker/)和更完整的[无需连接银行的预算应用指南](/zh/blog/budget-app-without-bank-linking/)。

为每个账户确定一个截止时间，设在你准备导入的第一笔交易之前。从对账单中取出该时点的已入账余额，再按这个准确金额补录一笔日期早于首笔交易的期初记录。之后只导入截止时间之后的交易。对于债务，即使对账单把欠款印成正数，也要在系统里录为负余额。

Expense Budget Tracker 没有专门的期初余额记录类型，所以这条初始记录必须使用普通的收入或支出账本机制。给它一个明确的分类，例如 `Opening balance`。这个标签便于审计，但不会自动把记录排除在报表之外。把记录放在截止日期之前，再从后续交易开始分析正常的收入和支出。不要先录入今天的余额，再导入形成该余额的历史交易。如果余额仍然对不上，应检查截止时间、待处理交易、手续费、利息和遗漏的转账，不要用一条来源不明的调账记录强行补平。[对账指南](/zh/blog/how-to-reconcile-your-budget-with-your-bank-balance/)给出了更完整的步骤。

余额的正负号会替你完成一部分净资产计算：

- 活期账户等资产账户通常以正余额结余
- 信用卡或其他债务通常以负余额结余
- 从活期账户向信用卡还款，会减少活期余额，同时让信用卡的负余额向零靠近

最后这笔资金移动属于内部转账。还款时不应再产生一笔新的支出；刷卡消费时，那笔费用已经记录过了。

## 让转账保持中性

转账一不小心就会把收入或支出算高。把钱从活期账户转到储蓄账户，只是换了资产所在的位置，不会改变家庭净资产。

Expense Budget Tracker 用两条关联的账本记录表示转账：来源账户记负数，目标账户记正数。两边缺一不可。同币种转账的本金应该金额相等、符号相反。

跨币种转账时，在来源账户记录换出的金额，在目标账户记录实际收到的金额，各自使用账户的原币种。如果银行从来源账户的扣款中收取手续费，应把手续费拆成一条单独的支出记录，不要把它藏在转账里。例如，来源账户扣了 $1,005，其中 $1,000 用于兑换，就应该记为一笔 $1,000 的转账和一笔 $5 的手续费。本金仍是内部资金移动，手续费才是真实支出。报告币种下的总额也可能发生变化，因为应用采用的每日汇率未必与银行实际使用的汇率一致。

向储蓄账户转钱、偿还信用卡和向券商账户入金，都应采用同样的处理方式。券商入金会让一个账户增加、另一个账户减少，它不是投资收入。市场波动或利息以后可能改变投资价值，但入金本身并没有创造价值。

有关原币种和报告币种换算的更多细节，请参阅[外籍人士多币种预算指南](/zh/blog/multi-currency-budgeting-for-expats/)。

## 用账户组和流动性辅助核查

Balances 页面提供了两个实用的账户核查维度。

**Account group（账户组）**可以设为 `regular` 或 `investment`。`regular` 适用于活期、现金、储蓄、信用卡和贷款；`investment` 则将手动估值的券商或养老金账户总额，与通过日常交易核对的账户分开。

**Liquidity（流动性）**可以设为 `high`、`medium` 或 `low`。这些标签由你根据家庭情况定义，应用不会替你判断。你可以把活期账户标为 `high`，需要提前通知才能取款的储蓄账户标为 `medium`，退休账户标为 `low`。定义一次，之后保持一致即可。

页面随后会按以下维度汇总余额：

- 按原币种
- 按流动性
- 按 `regular` 或 `investment` 账户组
- 分别显示正余额总计、负余额总计和合并余额

正余额和负余额两列按照余额符号给账户分组。它们适合用来核查资产与债务，但并不是正式的法律或会计分类。合并数字是否真是你理解的那个含义，仍取决于账户的设置方式。

## 投资怎么记，才不会把它硬当成投资组合追踪器

对于手动维护的投资账户，应记录每家机构的账户总额，而不是单项证券。

一个可行的月末流程如下：

1. 把现金入金和提现记为券商账户与相关现金账户之间的转账。
2. 在核查日期打开券商对账单，记下账户以原币种计算的总价值。
3. 将对账单价值与账本计算出的券商账户余额进行比较。
4. 如果对账单价值更高，把差额记为一条正数的收入类记录；如果更低，则记为一条负数的支出类记录。使用一个专门的分类，例如 `Investment valuation adjustment`，并采用对账单日期。
5. 将账户标记为 `investment`，再按照自己的定义设置相应的流动性等级。

第 4 步有一个重要限制：Expense Budget Tracker 没有投资估值专用的记录类型。这类调整使用普通的收入或支出机制，因此只要报表日期范围包含调整日期，它们就会影响收入和支出报表；系统不会按分类自动排除。它们只是账务调整，并不表示你真的收到了收入或花出了现金。如果这个取舍让预算报表变得难以理解，就用专门的投资组合追踪器记录投资表现，而 Expense Budget Tracker 只记录进出券商账户的现金。

产品不知道券商账户总额来自基金、债券还是尚未投资的现金。它无法刷新价格、计算资产配置或解释投资表现。它只会保留你录入的机构账户总额，并将其计入家庭余额视图。

## 一个假设的多币种示例

假设一个家庭使用 EUR 作为报告币种。下面的数据只用于说明，汇率也是刻意设置的假设值，并非当前市场报价。

假设报告换算采用 **1 USD = 0.92 EUR**：

| 账户 | 原币余额 | 账户组 | 流动性 | EUR 等值金额 |
| --- | ---: | --- | --- | ---: |
| EUR 活期账户 | €4,800 | 普通 | 高 | €4,800 |
| USD 储蓄账户 | $10,000 | 普通 | 高 | €9,200 |
| EUR 信用卡 | -€1,200 | 普通 | 高 | -€1,200 |
| USD 券商账户总额 | $25,000 | 投资 | 低 | €23,000 |

正余额合计为 €37,000，负余额合计为 -€1,200，因此合并余额是 **€35,800**。

用标准公式表示：

**资产（€37,000）- 负债（€1,200）= 净资产（€35,800）。**

按账户组查看，还可以得到另一组实用的拆分：

- 普通账户：合计 €12,800
- 投资账户：合计 €23,000

现在假设有 €500 从 EUR 活期账户转入 EUR 储蓄账户。来源账户减少 €500，目标账户增加 €500，所以合并净资产仍为 €35,800。如果转账一边误记为支出，另一边又误记为收入，最终账户余额或许还能修正，但月度预算反映的情况会是错的。

这个例子也说明了统一报告币种的用处。你可以继续按各账户的原币核查，同时得到一个家庭总额。即使没有发生任何交易，换算后的总额也会随汇率变动。这只是换算口径带来的变化，不一定代表出现了新的收入或支出。

## 让数字保持可信的月度核查流程

自动更新本身不能让净资产追踪器变得可靠。真正的可靠，是每个账户都有一套可以重复执行、能回溯到原始单据的核查方法。

条件允许时，每个月都使用同一个核查日期，然后依次完成以下步骤：

1. **收集来源余额。** 下载或打开所有纳入范围的银行、信用卡、贷款和投资账户对账单。无需把任何凭据连接到 Expense Budget Tracker。
2. **导入或录入新流水。** 按账户的原币添加已经入账的交易，不要混用待处理金额和已入账金额。
3. **配对内部转账。** 检查转入储蓄、信用卡还款、券商入金和跨币种兑换。两边都应存在，任何手续费都要单独记录。
4. **核对现金和债务账户。** 将账本计算出的每个账户余额与对账单比较。先查清差异，不要急着添加一条调账记录来补平。
5. **更新手动维护的投资总额。** 在同一个核查日期，录入账本余额与机构账户总额之间的差额，并使用专门的调整分类。请记住，只要收入或支出报表的日期范围包含这一天，调整记录就会出现在报表中。
6. **查看 Balances 警告。** 缺少汇率的警告意味着至少有一种货币无法计入报告币种总额。不要把不完整的换算总额当成净资产。
7. **检查数据是否够新。** 应用会显示最近一笔非转账活动；如果某个活跃账户沉寂太久，而且明显偏离近期的交易节奏，也会给出提醒。这个提醒只是提示你检查是否漏了导入，并不能证明数据一定缺失。
8. **核查各项拆分。** 对比正余额和负余额、普通账户和投资账户，以及高流动性和较低流动性总额。大幅变化都应该能追溯到交易、手动估值或汇率变动。
9. **记录核查日期。** 如果使用图表或外部月度笔记，请用准确的截止日期标注结果，这样两次快照才有可比性。

## “无需连接银行”意味着什么，又不意味着什么

不自动同步银行，意味着 Expense Budget Tracker 不会要求你提供网银凭据，也不会持续从银行拉取交易。数据由你通过手动录入、核查过的对账单导入或智能体工作流程来提供。

但这并不代表数据只存在你手里。使用托管版 Web 应用时，财务数据会由托管服务存储。如果希望在自己控制的基础设施上运行软件，这个项目是开源的，并提供[自托管指南](/zh/docs/self-hosting/)。请根据自己的隐私和维护要求选择部署方式。

目前有四种使用产品的方式：

- 使用托管版 Web 应用进行日常核查
- 通过托管版 MCP 连接兼容的 AI 客户端
- 让终端智能体和直接 HTTP 客户端使用 Agent API
- 自托管部署

技术用户应从 `GET https://api.expense-budget-tracker.com/v1/` 开始了解 Agent API。读取使用 `POST /v1/sql/query`；明确批准的写入使用 `POST /v1/sql/execute`。智能体可以协助导入对账单和对账，同时由用户审核拟议的更改。[入门指南](/zh/docs/getting-started/)介绍了可用的入口。

## 什么时候它更适合替代电子表格

如果只做一份简单的年度快照，电子表格完全够用。但当公式、手工复制的余额、转账标签和汇率都要靠记忆维护时，它就很容易出问题。

如果你希望做到以下几点，Expense Budget Tracker 会是更可靠的**个人财务电子表格替代方案**：

- 从交易账本出发，跨账户追踪净资产
- 完整保留原币种
- 查看一个换算为报告币种的总额
- 分开统计普通账户和投资账户
- 不连接银行凭据
- 查看开源实现，或自行托管
- 使用智能体协助导入对账单和完成对账

如果你最关心的是“每个券商账户里到底持有哪些资产？”或“按照这些回报率假设，我什么时候可以退休？”，它就不适合作为主要工具。这些问题需要持仓数据、实时或定期更新的估值，以及专门的建模功能。

合适的中间方案，是使用一套**多币种净资产追踪器**：现金和债务根据真实交易对账，投资账户总额由手动定期更新，转账保持中性，同时完全不需要连接银行。

本文介绍的是一种财务记录流程，不构成针对个人的财务、税务、法律或投资建议。
